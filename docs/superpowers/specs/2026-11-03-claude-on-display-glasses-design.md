# Claude on Meta Ray-Ban Display — v1 design

## Goal
Личный чат с Claude на Meta Ray-Ban Display: ввод диктовкой / рукописью / экранной клавиатурой, ответ текстом на дисплее плюс озвучка. Пользуется один человек (владелец очков). Готово к использованию в течение дня-двух.

## Success criteria
- Приложение открывается из меню приложений на очках (Web App по HTTPS-ссылке).
- Фраза, введённая через системный композер, возвращает ответ Claude за разумное время (несколько секунд) и показывает его читаемо на 600x600.
- «Voice on» озвучивает ответ через `speechSynthesis`.
- API-ключ нигде не лежит в клиентском коде или репозитории.
- Посторонний, узнавший URL, не может тратить кредиты.

## Out of scope (v1)
Фото с камеры очков, «Hey Meta»/WebMCP (Meta AI недоступна в Венгрии), нативное приложение DAT, история чатов между сессиями, мультипользовательность, публикация в каталоги.

## Architecture
Один проект на Vercel, два блока на одном origin (чтобы не упереться в CORS):
1. **Фронтенд** — React + Vite + TS, `@wearables-ui-toolkit/mrbd`, мета-тег `mrbd-web-app-capable`. Бюджет: <300 KB первой загрузки, <15 запросов.
2. **`/api/chat`** — serverless-функция Vercel. Принимает историю сообщений, проверяет токен, вызывает Claude API, отдаёт ответ (стриминг, если простой по стабильности; иначе целиком).

## Frontend
- Экран чата: пузыри сообщений, статус «Thinking», кнопка Dictate / поле ввода (открывает системный композер), кнопка «+ New» (сброс диалога), переключатель «Voice on».
- Чёрный фон (на аддитивном дисплее чёрный = прозрачный), крупный шрифт, длинные ответы прокручиваются.
- Состояние диалога только в памяти страницы. В `localStorage` (в try/catch): токен доступа и настройки Voice/модель.
- Первый запуск: ввод токена через тот же композер.

## Backend (`/api/chat`)
- Ключ Anthropic только в env-переменной `ANTHROPIC_API_KEY`; токен доступа в `ACCESS_TOKEN`.
- Заголовок `Authorization: Bearer <token>`, сравнение постоянным временем; иначе 401.
- Лимиты: максимум длины сообщения и числа сообщений в истории, `max_tokens` ограничен; простой rate limit по IP/токену (в памяти инстанса, best effort).
- Системный промпт: отвечать по-русски (или на языке пользователя), кратко (до ~40 слов), без markdown и эмодзи, так как экран крошечный.
- Модель по умолчанию `claude-haiku-5-5`, переключение на `claude-sonnet-5-5` через env `MODEL`.
- Защита от расходов: лимит в консоли Anthropic ($5/мес).

## Error handling
Сеть/401/429/5xx показываются короткой строкой на экране (например «Нет связи», «Неверный токен»). Повтор по нажатию.

## Testing
- Unit: валидация и авторизация в `/api/chat` (токен, лимиты, формат), мок Claude API.
- Ручной: Meta Ray-Ban Display Simulator (Chrome extension), затем на реальных очках через QR/«Add a web app».

## Delivery
GitHub-репозиторий → Vercel (env: `ANTHROPIC_API_KEY`, `ACCESS_TOKEN`) → URL → добавление в очки: Meta AI → Devices → Display Glasses → App connections → Web apps → Add.

## Risks / open items
- Системный композер требует прошивку v127+ и Meta AI app v272+ (проверить на очках).
- Если Web App не сможет звать `fetch` к собственному origin или `speechSynthesis` не заработает, упадём до текстового режима без озвучки.
- Требования Meta к Web Apps (acceptable use) для личного использования не блокируют; для публикации прочитать отдельно.
